# 数绿融通绿色信贷智能体（公网演示版）

本项目为南京农业大学竞赛项目「数绿融通」的公网只读演示版本，基于本地8530端口phase2工作台改造，所有数据均为合成脱敏或公开来源数据。

## 本地运行
```bash
pip install -r requirements.txt
python -m green_model.web_app_phase2
# 访问 http://127.0.0.1:8530/dashboard
```

## 云端启动
```bash
# 云平台自动注入PORT环境变量，默认监听0.0.0.0
python -m green_model.web_app_phase2
```

## 核心特性
1. 完整保留phase2工作台全部页面与青屿100MW风电全链路演示案例
2. 默认公网只读模式，关闭所有匿名写入、上传、删除操作
3. 内置安全响应头，防止XSS、点击劫持、MIME嗅探
4. 跨平台PDF生成，自动适配Linux中文字体
5. BERT模型无权重时自动降级，明确标注离线演示结果，不伪造实时推理
6. 提供 `/health` 健康检查接口，适配云平台探活

## 合规声明
- 所有案件数据均为合成脱敏演示数据，不包含任何真实客户信息
- 所有模拟规则保持 `is_mock=1` 标记，不代表任何商业银行内部规则
- 系统不会自动作出授信审批、拒绝、停贷或违规认定
- 所有分析结果仅用于竞赛演示，不构成任何业务建议
